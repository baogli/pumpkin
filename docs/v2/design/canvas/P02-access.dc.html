Доступы — только когда нужныPumpkin просит разрешение в момент первого использования функции. Любой пункт можно пропустить — остальное продолжит работать.
Папки
Разрешено
Загрузки, папка скриншотов и Movies/Pumpkin — только выбранные тобой.Без этого: остальные папки и модули работают.
Запись экрана
Нужен перезапуск
Нужна, чтобы снять выбранный дисплей. Звук в этот пункт не входит.Без этого: буфер, очистка и настройки работают.
Микрофон
Нужен доступ
macOS называет так и loopback-входы аудиокарты — без него не будет звука.Без этого: запись «Без звука», буфер и очистка работают.
Универсальный доступ
Не запрошено
Для вставки одним нажатием и позиции у текстового курсора.Без этого: история и «Скопировать» работают, вставляешь сам ⌘V.
Вернулся из «Системных настроек»? Проверим доступ ещё раз — пока не проверим, ничего не считаем разрешённым.
