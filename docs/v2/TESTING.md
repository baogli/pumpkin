# Pumpkin 2.0 — реализация и проверка

Дата: 2026-10-01. Статус: development preview, локальная приёмка. Стабильный релиз остаётся 1.0. Наличие universal binary не подтверждает аппаратную запись на Intel.

## Реализовано

- Нативная оболочка по согласованному Liquid Glass canvas: Запись, Буфер, Очистка, общие настройки/доступы/онбординг, меню Pumpkin. RU/EN, system/light/dark, glass на macOS 26 и material fallback на macOS 14–15. Кнопка записи доступна при минимальных 760 × 600 pt; настройки складываются вертикально при узком окне.
- Один выбранный дисплей через ScreenCaptureKit. MP4 H.264/HEVC, 30/60 fps, 1080/1440/2160/native без апскейла, качество, курсор, отсчёт, выбор папки и импорт MP4.
- Аппаратный звук AUHAL: стабильный UID, явные однобазные L/R, подтверждение пары, проверка уровней, silence/clipping/drop warnings. Preallocated C ring, без Swift/аллокаций/блокировок на real-time callback. Режим без звука создаёт MP4 без аудиотрека.
- Отмена подготовки/отсчёта, идемпотентный Stop, ожидание завершения writer, остановка при ошибке источника/сне/неактивной сессии, безопасный выход. Исходная причина и ошибка сохранения остаются видимыми; частичный MP4 не выдаётся за успешный экспорт.
- История текста в RAM: opt-in, максимум 60, точный dedupe, исключённые типы всех pasteboard items, pause/clear/disable. Быстрый popup с локальными клавишами, копированием без AX и проверкой исходной цели при автоматической вставке. Ownership token + changeCount защищают новую копию пользователя от отложенного восстановления.
- Общее файловое состояние schema v2 с backup v1. Сохранены действующие таймеры, пауза, Корзина, миграция ShelfLife и настройки. Ожидающие решения сохраняются без expiresAt; скрытый/paused запрос не запускает политику без ответа.
- Собственные записи регистрируются до создания файла, защищены от автоочистки и после рестарта. Все `.partial.mp4` исключены; похожее имя download не даёт защиты. Явный срок использует общий expiry engine и одну файловую identity.
- Независимые источники очистки и разрешения. Явный буфер/запись откладывают автоматические панели; после записи показана сводка. Глобальные клавиши изменяются в настройках, конфликт регистрации виден пользователю. Цифры/стрелки/Return не зарегистрированы глобально.

Запись адаптирована из MIT Able Recorder `099938c`; полная атрибуция включена в THIRD_PARTY_NOTICES и app bundle. Clipboard написан самостоятельно; код Vee без опубликованной лицензии не включён. Импорт прежних предпочтений выполняется только кнопкой пользователя, без экспорта RAM-истории и переноса разрешений.

## Команды

```bash
swift test
scripts/qa-app.sh /tmp/pumpkin-v2-cleanup
swift run PumpkinV2QA /tmp/pumpkin-v2-ui
swift run PumpkinMediaQA /tmp/pumpkin-v2-media
scripts/build.sh
scripts/package-release.sh
```

Оконные QA запускать по одному в локальной графической macOS-сессии. PumpkinQA использует временные файлы и настоящую Корзину, затем восстанавливает тестовые объекты. PumpkinV2QA использует отдельный pasteboard, временный manifest и подставленные названия устройств/дисплеев; не запускает живую запись. Медиа QA синтетический: не захватывает рабочий стол/микрофон и не подтверждает аппаратный loopback.

## Локальные доказательства

Среда: macOS 26.5.2, Xcode 26.6, Apple Silicon.

| Проверка | Результат / границы |
| --- | --- |
| Unit/integration | 82 tests / 14 suites passed. Включают прежнюю файловую логику, clipboard ownership, все protected types, pause/disable, schema backup, pending persistence, identity/rename/replacement, собственные MP4, screenshot metadata, popup geometry и запись shortcut |
| Файлы / AppKit | 80 checks passed в нативном QA-bundle: реальные watcher/Корзина/возврат, rename/move, пауза, очередь и перезапуск, геометрия, hit testing, клавиатура и сохранение фокуса внешнего приложения |
| Объединённый UI | 18 layouts/snapshots; меню, видимый запрос и стрелки/Return, запрет подтверждения скрытого запроса из меню, quick clipboard copy-only, Return/Esc и приоритет панелей |
| Стерео MP4 | 3 cases: H.264/30/48 kHz, H.264/60/44.1 kHz, HEVC/30/96 kHz → AAC stereo 48 kHz. Полный decode; независимые синтетические 1000/1500 Hz, длительность около 2.5 s, финальный статичный кадр, fast-start, отсутствие drop |
| Video-only MP4 | H.264 и HEVC, по 61 декодированному кадру, около 2.5 s, ровно один video track и ноль audio tracks |
| Сборка | Release bundle arm64 + x86_64; hardened runtime + audio-input entitlement, ad-hoc signature. Apple notarization не выполнялась |

AppKit-harness запускается через `scripts/qa-app.sh` как подписанный временный app bundle: WindowServer-фокус обычного CLI отличался от установленного приложения. Он доставляет синтетические события через NSApplication.sendEvent; очередь postEvent не гарантировала их доставку неактивному тестовому процессу. Это проверка AppKit hit testing/responders, а не подтверждение вставки во всех внешних приложениях. Реальная вставка и размещение у курсора требуют отдельных сценариев ниже.

Установленная сборка открыта обычным запуском. В её реальном интерфейсе подтверждены онбординг, независимые отсутствующие TCC-доступы и сохранение прежних таймеров при обновлении. Попытка отдельной интерактивной QA-проверки через компьютерный инструмент завершилась таймаутом инструмента и не засчитывается. Screen Recording/Microphone/Accessibility не выдавались обходным способом.

Скриншоты QA содержат вымышленные данные. Canvas — источник дизайна; screenshots — реализация, не запись настоящего USB-интерфейса или внешнего дисплея.

## Оставшаяся аппаратная приёмка

| ID | Что проверить на распространяемом Pumpkin bundle |
| --- | --- |
| A02 / A08 | Выдача и отзыв Screen Recording/Microphone/Accessibility; перезапуск, если его требует macOS; отключение реальных источников, смена sample rate и сон |
| A03–A05 | Встроенный и настоящий внешний монитор. 10 секунд Ableton с музыкальным сигналом; явная пара loopback L/R реальной карты. Полностью декодировать MP4 и прослушать экспорт человеком; уровни или наличие аудиотрека не заменяют прослушивание |
| A09 | Минимум 30 минут под нагрузкой. До запуска принять предел drift (предлагается 100 ms за 30 минут); измерить media timestamps/положение общей A/V-метки в начале и конце, RSS и drops. Синтетические 2.5 s этого не доказывают |
| A11 / A12 | Автоматическая вставка в реальные редакторы/браузер, смена фокуса во время доставки и новая копия пользователя; caret на краях настоящих дисплеев. Copy-only и правила восстановления проверены отдельно |
| A17 / A18 | Посмотреть реальную запись с главным окном, меню, буфером и диалогами Pumpkin поверх кадра; ни одно окно приложения не должно попасть в экспорт. Проверить Stop & Quit и незавершённую запись после force quit на тестовом MP4 |
| A19 / A20 | VoiceOver и keyboard-only, Reduce Motion/Transparency, runtime macOS 14–15, настоящая запись на Intel. Наличие Intel-среза в binary не подтверждает runtime |

Не менять настройки звуковой карты/DAW или сторонних приложений ради проверки автоматически. Новые TCC-разрешения выдаются штатным способом для `app.pumpkin.Pumpkin`; доступ соседних приложений не считается доступом Pumpkin. Реальные записи экрана, clipboard text и личный state не коммитить.

## Релиз

В ветке лежат исходный дизайн, реализация, тесты и инструкции сборки. ZIP собирается локально без пользовательского state и RAM-истории. До прохождения аппаратных пунктов выше распространять как preview, не объявлять A01–A20 полностью выполненными и не заменять стабильный выпуск 1.0 обещанием завершённой аппаратной приёмки.
