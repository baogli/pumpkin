# Pumpkin 2.0 — задание дизайнеру

Читать вместе с [продуктовой спецификацией](PRODUCT_SPEC.md): она задаёт поведение, этот документ — состав дизайн-пакета. Статус: новая версия до реализации. Дата: 2026-10-01.

## 1. Характер приложения

Дружелюбная маленькая утилита, которая помогает разобраться с временными материалами. Образ Pumpkin — тёплая, немного смешная тыква. Она уместна в онбординге, пустых состояниях и коротком сообщении об успехе. Во время записи или выбора файла важнее информация и ясные действия.

Ориентир — нативное macOS-приложение: системная типографика, знакомые поля и меню, аккуратные материалы, работа с клавиатуры. Сохранить узнаваемость [текущей иконки](../icon.png) и [иллюстрации](../pumpkin-illustration.png); дизайнер может предложить более цельную систему на их основе. Не делать приложение похожим на Halloween-игру.

Оранжевый — бренд и акцент действия; красный — активная запись, серьёзная ошибка или явное опасное действие. Статусы сопровождаются текстом/иконкой, а не только цветом. Светлая и тёмная темы равноправны. На macOS 26 можно использовать системное стекло, на macOS 14–15 нужна читаемая версия на стандартных материалах без эффекта стекла.

Интерфейс нужен на русском и английском. Основной дизайн можно выполнить на одном языке, но проверить ключевые экраны на обоих; русский текст и длинные имена не должны обрезать кнопки.

## 2. Структура и размеры

Основное окно: боковая навигация **Запись / Буфер / Очистка**, заголовок выбранного раздела, содержимое, доступ к настройкам. Во время записи — общий компактный статус с «Остановить и сохранить», видимый при переходе между разделами.

| Поверхность | Начальный ориентир для макета | Требование |
| --- | --- | --- |
| Главное окно | 920 × 700 pt, минимальный вариант 760 × 600 pt | Изменяемый размер, прокрутка при нехватке места; основной CTA доступен |
| Меню строки меню | 320–380 pt шириной | Быстрые действия, статус без длинной навигации |
| Быстрый буфер | 360–520 pt шириной | У курсора/мыши; ограничение по экрану, раскрытие истории с прокруткой |
| Запрос срока | 360–420 pt шириной | Один файл или группа; основные действия не скрываются |
| Настройки | Около 760 × 600 pt | Разделы, доступы и пояснения; стандартное изменение размера |
| Toast | По длине короткого сообщения | Краткое подтверждение, ясный возврат/открытие при необходимости |

Размеры — отправные точки, а не жёсткий пиксельный контракт. Макеты используют macOS points, а не смешивают их с размером видеокадра в pixels.

## 3. Обязательные экраны

Назвать фреймы идентификатором и состоянием: например `P03 / Запись / Готово`, `P03 / Запись / Устройство отсутствует`. Один экран может иметь несколько фреймов.

| ID | Экран | Обязательное содержимое и действия |
| --- | --- | --- |
| P01 | Знакомство и выбор функций | Pumpkin; три короткие карточки; включение нужных функций; «Продолжить», «Позже»; объяснение локального хранения |
| P02 | Настройка доступов | Отдельные карточки папок, Screen Recording, Microphone, Accessibility; объяснение назначения; запрос/настройки/проверка; пропуск |
| P03 | Запись: настройка | Дисплей, источник звука, L/R, проверка звука; качество/размер/fps/кодек; курсор/отсчёт; папка; оценка размера; «Начать запись» |
| P04 | Запись: отсчёт | Выбранный экран и звук, 3 → 2 → 1, «Отмена»; нет ложного статуса «Записываем» до старта |
| P05 | Запись: активная и завершение | Длительность, размер, L/R, экран, формат, предупреждения; «Остановить и сохранить»; отдельный вариант «Сохраняем MP4…» |
| P06 | Результат и собственные записи | Карточка последней записи и список; открыть/Finder/путь/назначить срок; «Новая запись»; статус недоступного/промежуточного файла |
| P07 | Буфер: главное окно | До 60 элементов, превью выбранного текста, время, «Скопировать», пауза истории, очистка; объяснение хранения до выхода |
| P08 | Буфер: быстрый popup | 5 строк по умолчанию, номера 1–9, hover/keyboard selection, «Ещё история», режим вставки или копирования, пустое состояние |
| P09 | Очистка: список | Ожидающие решения, таймеры, Корзина; фильтры источника; сроки, изменение/навсегда/Finder/вернуть; пауза таймеров |
| P10 | Очистка: запрос срока | Имя и источник, превью, группа/количество, 6 сроков, «Готово», «Оставить навсегда», закрытие; отдельная версия для собственного видео |
| P11 | Меню Pumpkin | Быстрые входы в разделы, состояние таймеров, настройки, выход; активная запись и время с остановкой на первом плане |
| P12 | Настройки | Общие, Запись, Буфер, Очистка, Доступы, О Pumpkin; hotkey-конфликт, отключённый модуль, версия и open source |
| P13 | Сообщения и подтверждения | Таймер назначен, в Корзине/вернуть, восстановлено, скопировано, сохранено; очистка истории; выход во время записи; сбой финализации |

Экран P06 может быть частью раздела «Запись», а P12 — отдельным системным окном. Не нужно добавлять четвёртый раздел «Медиатека» только ради списка видео.

## 4. Обязательные состояния

### P01–P02: начало и доступы

- Новый пользователь, все функции ещё не настроены.
- Обновление с Pumpkin 1.0: очистка уже настроена, буфер и запись предлагаются дополнительно.
- Разрешение ещё не запрашивалось / дано / отказано / отозвано; нет доступа к одной из папок.
- Открыты системные настройки, пользователь вернулся — повторная проверка и понятный результат.
- Нужен перезапуск для применения системного разрешения; во время записи перезапуск недоступен.
- Выбор «Позже» оставляет доступные функции работоспособными. Не показывать обязательную стену из всех разрешений.

### P03–P06: запись

- Готово: один дисплей, валидная пара L/R, папка доступна.
- Несколько дисплеев, длинное название устройства, 12 и более каналов.
- «Без звука»: нет L/R и требования Microphone; отсутствие аудиоустройств не блокирует этот режим.
- Устройство не выбрано; ранее выбранное отсутствует; сохранённые каналы недействительны; сохранённый дисплей отключён.
- Проверка звука: сигнал только L, только R, оба; тишина; слишком высокий уровень/клиппинг; остановка проверки.
- Подготовка доступа/источника, отмена, отсчёт, отменённый отсчёт.
- Активная запись; смена раздела; окно закрыто, меню доступно.
- Тишина во время записи, обнаруженные пропуски, низкое свободное место, ошибка записи. Предупреждение не должно перекрывать остановку.
- Сохраняем MP4; повторный клик/горячая клавиша не запускает новую запись.
- Успешно сохранено; устройство отключилось, но файл удалось сохранить; сохранить не удалось и остался `.partial.mp4`; файл недоступен после перемещения/удаления.
- Пустой список собственных записей; много записей; очень длинное имя; видеозапись с явно назначенным таймером.

Ошибку, состояние устройства и сигнал различать. При тишине кнопка записи остаётся доступна, но пользователь видит предупреждение. При недоступном источнике начать запись через него нельзя. Для промежуточного файла не показывать обычные «Открыть видео»/«Назначить срок», как будто это готовый MP4.

### P07–P08: буфер

- Пусто; только один элемент; пять строк; девять строк; раскрытая история до 60.
- Однострочный текст, длинная ссылка, email, код, многострочный текст, emoji и длинное слово без пробелов.
- Hover мышью, выбор стрелками, одновременное присутствие указателя и клавиатурного выбора: приоритет последнего способа ввода.
- История на паузе; функция отключена; пользователь очистил историю.
- Accessibility отсутствует: явное «Скопировать», короткая подсказка «Затем ⌘V», popup у мыши.
- Исходное приложение исчезло/цель вставки недоступна: сообщение и возможность скопировать, без неожиданной вставки в другое окно.
- Popup около правой/нижней границы дисплея; масштабированный дисплей; смена монитора. Окно не выходит за видимую область.

История буфера может содержать личные данные. Не использовать реальные пользовательские тексты в дизайн-файле, демо или видео. Показ подробностей — явный выбор строки в основном окне; popup ограничивается коротким превью.

### P09–P10: очистка

- Нет файлов с таймером; есть ожидающие решения; источники выключены; нет доступа к папке.
- Новый download, новый скриншот, группа файлов, недоступное превью.
- Несколько оставшихся сроков: 8 минут, 2 часа, 3 дня; один истекает скоро. Показать относительное время и доступную точную дату.
- Таймеры на паузе; файл переименован; файл перемещён вне папки; файл недоступен.
- Перемещено в Корзину; восстановление успешно; исходное имя занято и создано свободное имя; файл больше не в Корзине.
- Ошибка перемещения в Корзину или возврата с понятным действием; состояние повторной попытки, без сообщения об успехе.
- Во время записи: новые файлы ожидают решения в списке, самопроизвольные popup не показываются; после записи — сводка.
- Собственное видео по умолчанию «Хранить бессрочно»; после явного назначения срока — обычный таймер с источником «Запись».

«Оставить навсегда» должно быть полноценным видимым действием. Дизайн не подталкивает автоматически удалять файл и не прячет сохранение за меню из трёх точек.

### P11–P13: общие состояния

- Значок Pumpkin: обычный, есть активный таймер, таймеры на паузе, идёт запись, финализация, проблема доступа.
- Во время записи её индикатор/время имеют приоритет над кольцом ближайшего таймера. Состояние очистки читается в открытом меню.
- Одна операция успешна, другой модуль требует доступа: доступная функция остаётся доступной.
- Конфликт горячих клавиш с другим модулем/системой/приложением; предложить изменение, не заявлять успешную регистрацию.
- Выход при записи: «Остановить и выйти» / «Отмена». При ошибке сохранения — причина, оставшийся файл и явное решение о выходе.
- Toast «Перемещено в Корзину» с «Вернуть»; истёкший toast не убирает возможность возврата из списка.

## 5. Сквозные сценарии для прототипа

### F01 — записать второй монитор со звуком

P11 → P03 → выбрать внешний дисплей → аудиокарта → Input 11 / Input 12 → P02 при необходимости → проверить L/R → остановить проверку → начать → P04 → P05 → остановить → финализация → P06 → открыть MP4. Прототип показывает выбранные каналы на всём пути и бессрочное хранение результата.

### F02 — быстрая запись без звука

P03 → «Без звука» → начать → P04 → P05 → остановить → P06. Запрос Microphone отсутствует, запрос Screen Recording остаётся.

### F03 — вставить предыдущий текст

Скопировано несколько демонстрационных строк → ⌥⌘V → P08 у курсора → выбрать номер 2 → popup закрывается → текст вставлен в исходное приложение. Отдельная ветка без Accessibility: выбрать номер 2 → «Скопировано — вставь ⌘V».

### F04 — срок для нового файла и возврат

Новый `demo-notes.pdf` → P10 → 1 день → «Готово» → P09 с таймером → истечение в демонстрации → P13 с «Вернуть» → возврат → подтверждение. Отдельные ветки «Оставить навсегда», закрытие без ответа и пауза таймеров.

### F05 — новый скриншот во время записи

P05 активен → системный скриншот появляется → popup не показывается → пользователь останавливает запись → P06 результат → сводка об ожидающем файле → P09 → P10 → выбранный срок. Нельзя назначить скрытый таймер до решения пользователя.

### F06 — устройство отключилось

P05 → исчезло аудиоустройство → остановка и финализация → P06 с причиной и сохранённым файлом. Вторая ветка: финализация не удалась → P13 с ошибкой и промежуточным файлом; никаких ложных сообщений «Сохранено».

### F07 — назначить срок собственному видео

P06 «Хранить бессрочно» → «Назначить срок» → P10 с подписью «Запись Pumpkin» → подтвердить → таймер виден в P06 и P09 как один объект → пауза/возврат работают по общим правилам.

## 6. Компоненты и взаимодействия

| Компонент | Варианты / правила |
| --- | --- |
| Навигация | Обычная, выбранная, badge ожидающих; запись не исчезает при смене раздела |
| Status item | Pumpkin + таймер/пауза/красная точка; короткий доступный текст для VoiceOver |
| Карточка дисплея | Выбран, не выбран, недоступен; имя и разрешение |
| Источник звука / селектор канала | Обычный, отсутствует, запрещён, длинное имя; L/R с номером канала |
| Индикатор уровня L/R | Тишина, сигнал, пик/клиппинг, устройство недоступно; текстовое состояние для доступности |
| CTA записи | Начать, отменить подготовку, отменить отсчёт, остановить/сохранить, сохраняем, недоступно с причиной |
| Строка видео | Готово, с таймером, недоступно, ошибка/partial; метаданные и действия |
| Строка буфера | Тип, номер, превью, время; hover, keyboard selection, copied, copy-only |
| Строка очистки | Источник, имя, срок, пауза, Корзина, недоступно, ошибка; единая логика действий |
| Выбор срока | 6 значений, выбранное, focus; «Навсегда» отдельным действием |
| Карточка доступа | Не запрошено, разрешено, нужен доступ; подходящий CTA |
| Notice / toast | Успех, информация, предупреждение, ошибка; действие и закрытие |
| Shortcut field | Нормальный, захват клавиш, конфликт, отключён; отмена изменения |
| Empty state | Текст, одна понятная следующая операция, лёгкая иллюстрация при уместности |

Дополнительные требования:

- Tab/Shift-Tab обходят доступные элементы; есть видимый focus ring. Esc закрывает popup/диалог, не завершает запись случайно.
- В запросе срока ←/→ выбирают срок, Return подтверждает, K оставляет навсегда; локализованная подсказка показывает реальные клавиши.
- Системные модальные диалоги и выбор папки должны соответствовать macOS, не превращаться в собственный веб-интерфейс.
- Безопасные имена файлов сокращаются в середине/конце с доступом к полному имени. Ошибки и предупреждения переносятся, не теряются в tooltip.
- VoiceOver получает название, роль, значение и причину недоступности. Минимум WCAG AA для текста; статус не кодируется только цветом.
- Reduce Motion уменьшает перемещения и пружинную анимацию. Reduce Transparency даёт непрозрачную читаемую подложку. Нельзя прятать элементы из-за незавершившейся анимации.
- Не использовать hover как единственный способ получить важное действие. Проверить управление только клавиатурой.

Для макетов: `demo-notes.pdf`, `Screenshot-demo.png`, `Recording-demo.mp4`, `https://example.com/pumpkin`, `const greeting = "Hello, Pumpkin";`, «Забрать прошлый фрагмент текста». Использовать вымышленные имена устройств «USB Audio Interface», дисплеев «Built-in Display», «External Display» и пути без личных имён. Не вставлять реальные клипы, рабочий стол или содержимое Downloads пользователя.

Короткие шутки возможны в приветствии и пустых состояниях. Ошибки доступа, потери записи и операции с файлами объясняются прямо.

## 8. Передача готового дизайна

Нужен редактируемый файл (например, Figma) с такими страницами:

1. **Overview** — навигация, карта F01–F07, принятые решения и вопросы.
2. **Foundations** — цвета, типографика, отступы, радиусы, материалы, иконки; light/dark и fallback.
3. **Components** — переиспользуемые компоненты и варианты из таблицы выше.
4. **Screens** — P01–P13 с основными и ошибочными состояниями.
5. **Prototype** — все сквозные сценарии, включая копирование без Accessibility и сбой записи.
6. **Handoff** — размеры, растягивание, поведение скролла/клавиатуры, анимации, экспортируемые SVG/PNG и лицензии дополнительных ассетов.

Перед передачей отметить, какой экран покрывает каждое состояние из раздела 4. Проверить основные сценарии в обеих темах, минимальный размер окна, длинные тексты и режим уменьшения прозрачности. Предлагаемые изменения продуктовой логики вынести отдельным списком, чтобы их можно было согласовать до разработки.
